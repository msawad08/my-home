# Miraie AC Control — Next.js skeleton

Minimal Next.js TypeScript skeleton for the Miraie AC control app.

Quick start:

1. Install dependencies

```bash
npm install
```

2. Create `.env` from `.env.example` and set `APP_PASSWORD`.

3. Run development server

```bash
npm run dev
```

API routes are under `pages/api` and a simple Miraie adapter stub lives in `src/providers/miraie`.

Deploy to Vercel by connecting this repository and using the default Next.js build.
